# الحديث المهجور (The Abandoned Hadith)

تطبيق مجاني لتعلم الأحاديث الصحيحة والسنن المهجورة، عبر القراءة اليومية،
الشرح المبسّط، الاختبارات القصيرة، ونظام نقاط (XP) وسلسلة تعلم يومية (Streak).

هذا المستند يصف الوضع الحالي للكود (التطبيق + لوحة تحكم المشرف + تكامل
Firebase)، وكيفية تشغيله وإعداد قاعدة البيانات، وما تبقّى لإنجازه.

## المتطلبات

- Flutter 3.22+ (Dart SDK `>=3.3.0 <4.0.0`).
- حساب Firebase (مجاني) لتفعيل تسجيل الدخول وقاعدة البيانات ولوحة التحكم.

## التشغيل لأول مرة

هذا المستودع يحتوي فقط على كود Dart (`lib/`) وملفات الإعداد، بدون مجلدات
المنصّات (`android/`, `ios/`, `web/`, ...) لأنها تُولَّد محليًا. لتشغيل
المشروع لأول مرة:

```bash
flutter create . --project-name hadeeth --org com.example --platforms=ios,android
flutter pub get
flutter run
```

الأمر الأول يولّد مجلدات المنصّات المطلوبة (`android/`, `ios/`, ...) دون
المساس بمجلد `lib/` أو ملفات الإعداد الموجودة. مجلدات المنصّات مستثناة من
Git عبر `.gitignore` حاليًا.

> ملاحظة: التطبيق يعمل بدون أي إعداد لـ Firebase أيضًا، باستخدام بيانات
> تجريبية محلية وحفظ التقدّم على الجهاز فقط (وضع الضيف). لتفعيل تسجيل
> الدخول، المزامنة، ولوحة تحكم المشرف، أكمل خطوات "إعداد Firebase" أدناه.

## إعداد Firebase

نسخة الويب من التطبيق مربوطة فعليًا بمشروع Firebase باسم `hadeeth-19906`
(الإعدادات في `lib/firebase_options.dart`، تحت `DefaultFirebaseOptions.web`).
لتفعيل تسجيل الدخول والمزامنة بالكامل، أكمل التالي من
[Firebase Console](https://console.firebase.google.com/project/hadeeth-19906):

1. من **Authentication → Sign-in method**، فعّل مزوّد **Email/Password**.
2. من **Firestore Database**، أنشئ قاعدة بيانات (وضع Production).
3. انشر قواعد الأمان الموجودة في `firestore.rules`:
   ```bash
   firebase deploy --only firestore:rules
   ```
   (أو نسخ محتوى الملف يدويًا إلى تبويب **Rules** في Firestore Console).

> لتشغيل التطبيق على Android/iOS بنفس المشروع، ثبّت FlutterFire CLI وشغّل
> `flutterfire configure` — يضبط إعدادات `android`/`ios` في
> `lib/firebase_options.dart` دون التأثير على إعدادات `web` الحالية، ويضيف
> ملفات إعداد المنصّات (`google-services.json`، `GoogleService-Info.plist`، ...):
> ```bash
> dart pub global activate flutterfire_cli
> flutterfire configure
> ```

بدون تفعيل Authentication و Firestore أعلاه، يستمر التطبيق بالعمل بالبيانات
المحلية التجريبية فقط (القراءة، الاختبارات، XP/السلسلة في وضع الضيف)، وتظهر
رسائل خطأ عربية عند محاولة تسجيل الدخول أو الحفظ من لوحة التحكم.

## تعيين أول مشرف عام (Super Admin)

لا توجد طريقة لتسجيل حساب كمشرف عام من داخل التطبيق (لأسباب أمنية - انظر
`firestore.rules`: لا يمكن لمستخدم تعيين نفسه كمشرف عام). لتعيين أول مشرف:

1. سجّل حسابًا عاديًا من شاشة "إنشاء حساب جديد" داخل التطبيق.
2. افتح **Firestore Console → users → (مستند المستخدم بمعرّف UID الخاص به)**.
3. غيّر قيمة الحقل `role` من `"user"` إلى `"superAdmin"`.
4. أعد فتح التطبيق (أو سجّل الخروج وأعد تسجيل الدخول). سيظهر تبويب
   "لوحة التحكم" في شاشة "حسابي"، ويتيح الوصول إلى `/admin` لإدارة الأحاديث
   والتصنيفات والمستخدمين.

من لوحة التحكم، يمكن للمشرف العام ترقية مستخدمين آخرين إلى مشرف عام لاحقًا.

## firestore.rules

ملف `firestore.rules` (في جذر المستودع) يحدد صلاحيات الوصول:

- `hadiths` و `categories`: قراءة عامة لكل المستخدمين (تشمل الزوار)، والكتابة
  محصورة بالمشرف العام (`role == 'superAdmin'`).
- `users/{uid}`: كل مستخدم يقرأ ملفه فقط (أو المشرف العام يقرأ الكل)، ينشئ
  ملفه بنفسه بدور `user` فقط، ويمكنه تعديل بياناته الشخصية بشرط عدم تغيير
  `role` أو `isDisabled` بنفسه (يمنع ترقية/تفعيل النفس). المشرف العام وحده
  يمكنه تغيير الأدوار، تعطيل الحسابات، أو الحذف.

## لوحة تحكم المشرف العام (`/admin`)

تظهر فقط للمستخدمين الذين `role == 'superAdmin'` (عبر `AdminGuard`)، وتتيح:

- **الأحاديث** (`/admin/hadiths`): عرض كل الأحاديث (منشورة/مسودة/مخفية)،
  إضافة حديث جديد بنموذج كامل (النص، المصدر، الشرح، الفوائد، الكلمات
  الغريبة، أسئلة الاختبار)، تعديل، تغيير الحالة (نشر/مسودة/إخفاء)، وحذف.
- **التصنيفات** (`/admin/categories`): إضافة/تعديل تصنيف (الاسم + أيقونة من
  مجموعة جاهزة)، إخفاء/إظهار، وحذف.
- **المستخدمون** (`/admin/users`): عرض كل المستخدمين، ترقية/تنزيل مشرف عام،
  وتفعيل/تعطيل الحسابات (مع حماية من تعديل المشرف لحسابه الخاص).

## الحالة الحالية

### تم تنفيذه

- بنية التطبيق الكاملة: التوجيه (`go_router`)، الثيم العربي (RTL، خطوط
  Tajawal / Noto Naskh Arabic)، وإدارة الحالة (`provider`).
- جميع الشاشات الأساسية: البداية، الرئيسية، تفاصيل الحديث، التصنيفات، أحاديث
  التصنيف، البحث، الاختبار، المفضلة، الحساب، وتقدّمي.
- نظام النقاط (XP) والمستويات (10 مستويات) والسلسلة اليومية (Streak) بالكامل،
  مطبَّق في `ProgressService` حسب قواعد المواصفة (5/5/10/+5/3/+5 XP، حد يومي
  40 نقطة).
- حفظ تقدّم المستخدم محليًا عبر `shared_preferences` (وضع الضيف).
- **تسجيل الدخول وإنشاء الحساب** عبر Firebase Auth (بريد إلكتروني/كلمة مرور)،
  مع ملف مستخدم في Firestore (`users/{uid}`) يحدد الدور (`user` /
  `superAdmin`) وحالة الحساب (مفعّل/معطّل).
- **مزامنة الأحاديث والتصنيفات مع Firestore** عبر `HadithRepository` و
  `CategoryRepository`، مع رجوع تلقائي للبيانات التجريبية المحلية إن لم تُعدّ
  Firebase أو كانت المجموعات فارغة (لا يتعطل التطبيق أبدًا).
- **لوحة تحكم المشرف العام الكاملة** (`/admin`): إدارة الأحاديث (إضافة،
  تعديل، نشر/مسودة/إخفاء، حذف)، التصنيفات (إضافة، تعديل، إخفاء/إظهار، حذف)،
  والمستخدمين (الأدوار، تفعيل/تعطيل الحسابات).
- قواعد أمان Firestore (`firestore.rules`) تحصر كل عمليات الكتابة على
  الأحاديث/التصنيفات بالمشرف العام، وتمنع المستخدمين من ترقية/تفعيل أنفسهم.
- **ربط مشروع Firebase الحقيقي** (`hadeeth-19906`) لإعدادات الويب في
  `lib/firebase_options.dart`.
- **عرض الويب بحجم الهاتف**: على المتصفح، يُعرض التطبيق داخل عرض ثابت (430px)
  بمحاذاة الوسط لمحاكاة شاشة هاتف، مع خلفية حول الإطار (`lib/app.dart`).

### لم يُنفَّذ بعد (خارج نطاق هذه الدفعة)

- **الإشعارات**: لا يوجد تكامل مع FCM أو إشعارات محلية. عنصر "تذكير حديث
  اليوم" في شاشة الحساب هو عنصر نائب فقط.
- يجب تفعيل **Email/Password** في Authentication، وإنشاء قاعدة **Firestore**،
  ونشر `firestore.rules` على مشروع `hadeeth-19906` قبل أن تعمل المصادقة
  والمزامنة فعليًا (انظر "إعداد Firebase" أعلاه).
- إعدادات `android`/`ios` في `lib/firebase_options.dart` لا تزال قيمًا مؤقتة
  (placeholders)؛ شغّل `flutterfire configure` لتفعيلها (انظر "إعداد
  Firebase" أعلاه).
- مجلدات المنصّات (`android/`, `ios/`, ...) غير مولَّدة بعد - شغّل
  `flutter create .` كما هو موضّح أعلاه.

### تنويه بشأن المحتوى

الأحاديث الثمانية في `lib/data/sample_hadiths.dart` هي أحاديث صحيحة موثّقة
من البخاري ومسلم، أُدرجت كبيانات تجريبية لبناء وتجربة الواجهات. **يجب
مراجعتها من قِبل مختصّ شرعي قبل استخدامها في نسخة الإنتاج**، وقبل إضافة محتوى
حقيقي عبر لوحة التحكم.
